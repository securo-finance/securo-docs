title: Implantação
description: Faça o deploy do Securo para produção com Docker Compose, Kubernetes ou Railway.

Pronto para hospedar seu próprio Securo? Escolha o guia que combina com a sua infraestrutura. Docker Compose (ou Podman) é o caminho mais fácil; quem usa Kubernetes tem um Helm chart oficial; e a Railway está coberta para hospedagem em plataforma como serviço.
