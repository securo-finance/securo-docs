Recurring transactions let you define subscriptions and regular bills that repeat on a schedule. Instead of manually adding the same transaction each month, Securo can generate them for you automatically.

![Recurring Transactions](/screenshots/recurring.png)

## How It Works

A recurring transaction is a template that defines:

- **Description**: What the payment is for (e.g., "Spotify", "Netflix USD")
- **Amount**: The transaction value, including currency
- **Frequency**: How often it repeats (weekly, monthly, quarterly, or yearly)
- **Next date**: When the next occurrence is due
- **End date** (optional): When the schedule stops generating occurrences
- **Status**: Active or paused

When the scheduled date arrives, Securo creates an actual transaction in the appropriate account based on the template. Generation runs automatically in the background every hour; each schedule also has an **auto-generate** toggle, and schedules with it off only create transactions when you click **Generate Pending**.

Monthly, quarterly, and yearly schedules preserve your intended day of the month: a subscription anchored to the 31st lands on April 30 and comes back to July 31.

## Creating a Recurring Transaction

1. Navigate to **Recurring** in the sidebar
2. Click **+ Add Recurring**
3. Enter the description
4. Set the amount and currency
5. Choose the account
6. Select the frequency (weekly, monthly, quarterly, or yearly)
7. Set the start date (and optionally an end date)
8. Click **Save**

## Managing Recurring Transactions

The recurring transactions page shows a table with all your schedules:

| Column     | Description                                    |
| ---------- | ---------------------------------------------- |
| Description | The name of the recurring payment             |
| Amount     | The value and currency (with converted amount) |
| Frequency  | How often it repeats                           |
| Next Date  | When the next transaction will be generated    |
| Status     | Active or paused                               |
| Actions    | Edit or delete the schedule                    |

## Generating Pending Transactions

Click **Generate Pending** to create all overdue recurring transactions at once. This is useful if you haven't opened Securo in a few days and need to catch up, or for schedules whose auto-generate toggle is off.

## Linking to Real Transactions

Recurring bills connect to the transactions that actually pay them. When a synced or imported transaction matches an upcoming occurrence with high confidence (same account, similar description and amount, close date), Securo links it to the schedule instead of creating a duplicate, replacing the generated placeholder if one exists. A linked transaction can be unlinked from its edit dialog.

The **recurring badge** in the transaction list appears only on transactions actually linked to a schedule, so two purchases that merely share a description are never both marked as recurring.

## Multi-Currency Subscriptions

For subscriptions in foreign currencies (e.g., a USD subscription on a BRL account), Securo shows both the original amount and the converted equivalent. This makes it easy to see the real cost of international subscriptions.

## Use Cases

- **Streaming services**: Netflix, Spotify, Disney+
- **Software subscriptions**: Cloud services, SaaS tools
- **Rent/mortgage**: Regular housing payments
- **Insurance premiums**: Monthly or annual insurance
- **Loan payments**: Regular debt repayments
