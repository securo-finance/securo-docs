This guide covers deploying Securo locally for testing and development.

If you are ready to deploy Securo to a live server, please see the [Docker Production](/docs/deployment/docker-prod) guide instead.

## 1. Prerequisites

- Docker Engine and Docker Compose plugin installed
- Git installed

## 2. Clone and Configure

Clone the repository to your local machine:

```bash
git clone https://github.com/securo-finance/securo.git
cd securo
```

Create a `.env` file with a secret key:

```bash
echo "SECRET_KEY=$(openssl rand -hex 32)" > .env
```

## 3. Start Securo

By default, the `docker-compose.yml` file builds the images from your local source code, which is great for development and hot-reloading.

```bash
docker compose up -d --build
```

Wait a few seconds for the database to initialize and the backend to start up. You can verify all containers are running:

```bash
docker compose ps
```

## 4. Access the Application

Once all containers are healthy, open your browser and navigate to:

**http://localhost:3000**

You can now log in, configure your accounts, and test Securo locally!
